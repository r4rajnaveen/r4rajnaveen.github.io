Privacy Policy

Last updated: 17 November 2026

RJ_app connector ("the app") is a private tool used only by its owner to manage the owner's own Google Ads accounts.

Data we access

With the owner's permission through Google sign-in, the app uses the Google Ads API (scope: https://www.googleapis.com/auth/adwords) to read and change advertising data in the owner's Google Ads accounts. This includes campaigns, ad groups, keywords, ads, budgets and performance reports.

How we use it

Data is used only to show reports to the owner and to make changes the owner requests. It is not sold, shared with third parties, or used for advertising or profiling.

Storage and security

Google Ads data is processed in memory for each request and is not stored. The OAuth credentials are kept as encrypted environment variables on the hosting server, and all connections use HTTPS.

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
